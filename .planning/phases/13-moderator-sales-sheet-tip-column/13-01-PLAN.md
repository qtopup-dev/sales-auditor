   - null or undefined returns null.
   - Any type other than string or number throws `new Error('INVALID_TIP')`. That rejects arrays, objects and booleans.
   - Take `String(raw).trim()`. An empty result returns null (blank = no tip, D-09).
   - Anything that does not match the regex `^\d{1,8}(\.\d{0,2})?$` throws. This one regex rejects signs, negatives, letters, exponents, commas and spaces (D-15), more than 2 decimals (D-13), and more than 8 integer digits, i.e. anything above 99999999.99 (D-14). A trailing dot such as `20.` is allowed, so the live frontend check does not flash an error mid-typing.
   - Canonicalize: split on '.', strip leading zeros from the integer part (keep at least one digit), right-pad the decimals to 2 with '0'. For example `007.5` becomes `7.50`.
   - A canonical value of `0.00` returns null (D-12: one representation of no tip). Otherwise return the canonical string.
